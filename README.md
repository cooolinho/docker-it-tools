## 🚀 Getting Started

### Prerequisites

- Docker
- Docker Compose

### Installation

```bash
git clone https://github.com/cooolinho/docker-it-tools.git
cd docker-it-tools
docker compose up -d
```

## 📋 Usage

```bash
# Start all tools
docker compose up -d

# View logs
docker compose logs -f

# Stop services
docker compose down
```
