## 📖 Über das Projekt

Ein Docker Compose-Setup, das verschiedene IT-Dienstprogramme und Werkzeuge für Systemadministration, Netzwerkdiagnostik und Service-Verwaltung bündelt.

## 🛠️ Tech-Stack

| Technologie | Version | Zweck |
|---|---|---|
| ![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white) Docker | Latest | Container-Laufzeit |
| ![Docker Compose](https://img.shields.io/badge/Docker_Compose-2496ED?style=flat-square&logo=docker&logoColor=white) Docker Compose | 1.29+ | Orchestrierung |

## ✨ Funktionen

- **Multi-Tool-Umgebung** — Verschiedene Dienstprogramme in einer Bereitstellung
- **Einfacher Zugriff** — Web-basierte Schnittstellen wo zutreffend
- **Ressourceneffizient** — Leichte containerisierte Werkzeuge

## 🚀 Erste Schritte

### Voraussetzungen

- Docker
- Docker Compose

### Installation

```bash
git clone https://github.com/cooolinho/docker-it-tools.git
cd docker-it-tools
docker compose up -d
```

## 📋 Verwendung

```bash
# Alle Werkzeuge starten
docker compose up -d

# Logs anzeigen
docker compose logs -f

# Dienste beenden
docker compose down
```
